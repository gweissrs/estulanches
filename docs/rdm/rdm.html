2Descrição da mudança

Objetivo: implantar a primeira versão do EstuLanches em containers. A versão digitaliza o cardápio, os pedidos e o acompanhamento em tempo real para estudantes, e o painel de gestão de pedidos, produtos e categorias para a cantina.

Arquitetura: SPA React servida pelo próprio backend Express (mesma origem) + API REST em camadas (rotas → middlewares → controllers → services → Prisma) + PostgreSQL em container separado, comunicando-se pela rede interna Docker.

Tecnologias: React 19 · Vite 7 · React Router 7 · Node.js 24.22 · Express 5 · TypeScript · Prisma ORM 7.8.0 (@prisma/adapter-pg) · PostgreSQL 17.12 · JWT · bcrypt · Zod · Helmet · Vitest 4 + Supertest · Docker multi-stage.
